# Starting decks

The Run Setup screen supports six decks. Focus the deck card and use Left/Right
to cycle; A advances to the next deck. The card back, name, and five-line
description update immediately.

| Deck | Effect |
|---|---|
| Red Deck | +1 discard every blind |
| Blue Deck | +1 hand every blind |
| Yellow Deck | Start with $10 extra |
| Green Deck | No interest; cash out $2 per remaining hand and $1 per remaining discard |
| Black Deck | +1 Joker slot and -1 hand every blind; Antimatter and Negative can expand it further up to the eight-Joker GBA row |
| Painted Deck | +2 hand size and -1 Joker slot |

The selected deck, adjusted hand size, and progression are saved and restored.
After Game Over, New Run returns to deck selection instead of silently starting
the previous/default deck.

The eight-Joker value is a rendering/storage ceiling, not a starting capacity.
Red, Blue, Yellow, Green, and Painted runs start from 5 Joker slots (Painted
reduces that to 4); Black starts from 6. Antimatter and rare Negative editions
are the only normal-run ways to grow toward 8.

Decks dependent on absent systems remain deferred: Magic needs Tarot cards;
Nebula needs held Planet consumables, while this build applies Planets
immediately on purchase; Ghost needs Spectral cards; Zodiac needs expanded shop
consumables; and Anaglyph needs tags.
